What it is

Matematex parses and renders LaTex math notation on Snap Spectacles. The use case that drove the Polynode project — Matematex needs SpaceSVG to render output cleanly, since LaTex rendering on the web traditionally builds on DOM, canvas, and SVG.

Status

Active. 1.0 release tied to Polynode’s SpaceSVG spec-compliance pass.
