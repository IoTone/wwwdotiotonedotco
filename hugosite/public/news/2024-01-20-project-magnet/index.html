Project MAG*Net launches: distributed IoT data sync for Matter / Zigbee / Thread

Project MAG*Net is an IoT data sync and control app, plus a distributed server for IoT data, across Matter, Zigbee, Thread, HomeKit, BLE, and Wi-Fi.

News · January 20, 2024 · 1 min read

Project MAG*Net is the spiritual successor to IoToneKit. It’s an IoT data sync and control app + a distributed server, designed to span Matter, Zigbee, Thread, HomeKit, BLE, and Wi-Fi without locking developers into a single platform. C++ + ESP32 + Arduino tooling.
