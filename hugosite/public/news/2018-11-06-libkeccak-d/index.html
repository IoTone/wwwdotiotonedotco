libkeccak-d: SHA-3 / Keccak for Dlang

A simple SHA-3 / Keccak hash function for Dlang, wrapping the keccak-tiny C implementation.

News · November 6, 2018 · 1 min read

libkeccak-d is a small Dlang wrapper around the keccak-tiny C implementation of SHA-3 / Keccak. A quiet brick used by other IoTone tooling that touches blockchain or content addressing.
